Titan Panel [Weapon Skills] is a addon to Display your Weapon Skills on Titan Panel!


## Features

Display: The addon displays all your weapon skills on the Titan Panel bar, giving you a quick and easy overview of your progress.
All the skills for your class that you can learn are displayed. If you haven't learned a skill yet, it will say “Not Learned, trainable.”

Label text, skill maximum, and session progress can be enabled or disabled by right-clicking on the active skill.

Coloring: Skill levels are color-coded:

Green -	Maxed out skill

Yellow - High skill

Orange - Medium skill

Red - Low skill

&nbsp;

## Requirements

This addon requires the __"Titan Panel"__ Core addon to function properly.
